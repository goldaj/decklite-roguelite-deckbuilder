# DeckLite — Build STABLE
- Fenêtre redimensionnable, cartes cappées à la taille de main=5, récompenses ajoutées immédiatement au deck.
- Bouton **Deck** en haut-gauche: affiche le panneau du deck piochable avec probabilités selon la vraie source (pioche ou défausse mélangée).
- Cartes cliquables avec animation, particules, nombres de dégâts.

## Lancer
```
python -m pip install -r requirements.txt
python main.py
```
